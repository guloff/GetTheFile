# GetTheFile

A downloader for Mac: videos from YouTube, VK, Rutube, TikTok and hundreds of other sites, `.m3u8` (HLS) streams and any file from a direct link — multi-threaded and resumable. No ads, no accounts, no data collection.

**Download:** the latest notarized `.dmg` is on the [Releases](https://github.com/guloff/GetTheFile/releases/latest) page. macOS 14 or later, Apple Silicon and Intel.

- Video by link: preview, quality up to 8K, MP4 / WEBM / MP3 / M4A
- Any file from a direct link: up to 16 threads, resumes after a dropped connection, pause or restart
- Playlists and link lists (`.txt`, `.md`), HLS with separate audio and AES-128
- Python, ffmpeg and the yt-dlp engine are installed by the app on first launch — no Terminal, no admin password
